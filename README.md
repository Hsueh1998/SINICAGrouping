# SINICAGrouping

這是一個純前端的籃球分組系統，已部署到 GitHub Pages。

- 頁面檔案：`index.html`
- 功能：
  - 新增、編輯、刪除球員
  - 搜尋、排序球員
  - 選擇出賽名單
  - 設定綁定組別（同組必同隊）
  - 產生平衡分組
  - 調整隊伍勝負分數並保存球員實力

## GitHub Pages 網址

https://hsueh1998.github.io/SINICAGrouping/

## 注意

球員資料會儲存在瀏覽器 `localStorage` 中，因此：

- 同一台電腦、同一瀏覽器可保留球員資料
- 不同瀏覽器或不同裝置不會自動同步

如果要進一步優化，我可以幫你加上：

- 出賽名單自動保存
- 匯入 / 匯出球員清單
- 固定隊伍數設定
- 更漂亮的首頁與說明頁面
